# 🎓 CertifyHub

> Plataforma para gerenciamento e organização de certificados digitais.

O **CertifyHub** é uma aplicação web desenvolvida para facilitar o armazenamento, organização e gerenciamento de certificados profissionais e acadêmicos em um único lugar.

O projeto foi desenvolvido com foco em aprendizado prático e aplicação de conceitos de desenvolvimento Full Stack, integração entre frontend, backend, banco de dados e gerenciamento de arquivos.

## 📋 Funcionalidades

### 👤 Usuários

- Cadastro de usuários
- Login
- Estrutura para recuperação de senha
- Gerenciamento de perfil

### 📜 Certificados

- Cadastro de certificados
- Listagem de certificados
- Visualização dos detalhes
- Edição de certificados
- Exclusão de certificados
- Categorias
- Código de certificação
- Link de validação
- Descrição
- Data de emissão
- Data de validade
- Carga horária

### 📎 Upload de arquivos

O sistema permite o envio de arquivos relacionados aos certificados.

São suportados:

- PDF
- PNG
- JPG
- JPEG
